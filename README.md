# Mpg-linear-regression

Built an end-to-end machine learning project to analyze and predict vehicle fuel efficiency (MPG) using the Auto MPG dataset.

• Cleaned and prepared the dataset by handling missing values and converting data into analysis-ready features.
• Performed Exploratory Data Analysis (EDA) to identify relationships between MPG and vehicle attributes such as horsepower, weight, displacement, and cylinders.
• Created visualizations using Matplotlib and Seaborn to identify trends and patterns in fuel efficiency.
• Built and trained a Linear Regression model using Scikit-learn to predict MPG.
• Evaluated model performance using regression evaluation metrics and analyzed prediction errors.
• Derived business-oriented insights into how vehicle specifications influence fuel efficiency.

Tech Stack: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Linear Regression, Exploratory Data Analysis, Data Cleaning.
